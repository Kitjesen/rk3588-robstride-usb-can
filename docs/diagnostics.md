# 诊断与接线

## 从 USB 到电机逐层检查

1. 使用 `lsusb -d 1d50:606f` 检查五路 USB-CAN 是否枚举。记录中五个设备位于 QinHeng `1a86:809e` Hub 下游。USB 总线号和地址会变化，长期配置用序列号。
2. 运行 `inventory` 读取版本和能力。`icount=0` 表示每个 USB 设备有一路 CAN；五路 Hub 由五个这样的设备组成。记录中 CAN 时钟为 48 MHz、feature 为 `243`（`0xF3`）。
3. 运行 `loopback`，检查每一路 `loopback_received=true` 且 `adapter_stopped=true`。该测试使用 SILENT 与内部 LOOPBACK，无法检测外部接线和收发器是否正常。
4. 将一颗已知正常且独立供电的电机接到 Hub 明确标号的一路，在正确接线和终端配置下运行 `identity`。按 USB 序列号记录应答通道，逐口建立映射。

物理映射表应由现场逐口测试填入，不能用 USB 枚举顺序猜测：

| Hub 实际端口标识 | USB 序列号 | 已确认的电机 ID | 验证日期 |
| --- | --- | --- | --- |
| 待核实 | 待填 | 待填 | 待填 |

“主板 CAN6”不是“五路 USB-CAN Hub 第六路”。原主板 CAN 口上的查询结果不能证明新 Hub 已与电机连通。

## ACK 错误怎样理解

ACK 错误表示发送器未收到其他正常接收节点的确认。它不能独立证明 Hub 固件坏了或电机损坏。优先检查电机是否独立供电、接线是否真正移到了新 Hub、CAN H/L 是否接反、参考地是否符合设备接线要求、波特率是否一致以及终端电阻是否正确。

CAN ACK 位不依赖应用层目标电机 ID；单纯“目标 ID 不对”通常只能解释没有身份应答，不能单独解释所有帧均缺少 ACK。

每条独立 CAN 总线通常在两端各放一个 120 Ω 终端。Hub 的拨码是否打开要由它是否位于总线端点决定，不是所有拨码一律打开。所有节点断电后测量 H-L，两个 120 Ω 并联时通常约为 60 Ω；其他电路会影响测量，应结合实际原理图判断。调整电机和 CAN 接线前先断电。

本次五路均出现带 ACK 错误标志的帧，例如 `can_id=0x20000024`；当时未取得电机 UID 应答。实际 Hub 端口接线仍未完成可靠确认，因此尚不能定位到某一根线或某一颗芯片。

## 身份查询的边界

RobStride type-0 身份查询使用扩展 CAN ID `0x0000FF00 | motor_id`，8 字节零载荷，主机 ID 为 `0xFF`。候选电机 ID 固定为 `1、2、3、4、127`。响应识别要求 RX 帧、扩展帧、type-0、有效源 ID、8 字节非全零 UID，并排除错误帧和 RTR；兼容响应目的字段为 `0xFE` 的设备。

识别器用于受控 RobStride 总线，未做请求事务关联，不能用于证明混合协议总线中任意 type-0 帧的设备身份。结果按 `(motor_id, uid)` 去重；同一 CAN 总线上重复 ID 会造成歧义，也不能靠一次查询可靠统计物理电机总数。

每次查询接收窗口约 0.4 秒，错误最多记录 16 条。出现错误或没有 USB TX echo 时停止追加查询，并停止 CAN 控制器以结束可能的自动重发。USB I/O 单次超时为 500 ms，实际总耗时可能超过接收窗口。

## 初始化和清理

脚本采用 `HOST_FORMAT → CAN stop → 排空旧包 → 1 Mbps 位时序 → CAN start`，使用 20 字节、无硬件时间戳的 classic CAN USB 帧。48 MHz 下位时序为 `prop_seg=1, phase_seg1=12, phase_seg2=2, sjw=1, brp=3`，采样点 87.5%。

脚本没有调用 `GsUsb.start()`，因为本次固定版本的该函数会执行 USB 设备 reset。显式控制顺序用于减少初始化的不确定性，不能据此认定它是此前 ACK 错误的根因。

内核已占用设备时拒绝 detach，也不停止内核管理的适配器。只有本脚本开始配置的适配器才进入停止清理。正常退出、异常和 SIGINT/SIGTERM/SIGHUP 均经过清理路径；若无法确认停止则中止后续通道。SIGKILL、断电或 USB 故障不能保证软件清理成功。

所有模式共用 `/run/lock/brainstem-usb-can-probe.lock`，它只防止遵循同一锁的探测工具并发。运行前仍须停止其他 USB-CAN 程序。结果 JSON 包含真实 USB 序列号及可能的电机 UID，仅存于默认忽略的 `results/`；分享前需脱敏。
