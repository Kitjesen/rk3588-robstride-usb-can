`evidence/` 中的 JSON 来自既有实测，替换 USB 序列号为一致的 `adapter-A` 等别名，删除启动 ID 和可变 USB 地址。别名只是脱敏标识，不代表面板端口顺序。原始包字段、错误、响应与停止状态保留。

## 本仓库脚本验证范围

`scripts/usb_can_probe.py` 是对板上原有独立探测脚本的整理，新增统一 CLI、可配置输出和明确退出码，并修正内核占用场景下的停止清理边界。发布时执行离线单元测试、语法检查和 CLI help 检查，未为文档发布再次操作实机。

离线测试覆盖：USB echo 不算电机响应、错误帧/RTR/空 UID 排除、有效身份解析、内核占用时不写控制命令、正常及异常退出停止、停止失败上报、退出码语义。模拟测试不能替代新脚本在目标系统的实际运行验收。

```bash
python -m unittest discover -s tests -v
python -m py_compile scripts/usb_can_probe.py
python scripts/usb_can_probe.py --help
```
